# Ownership:

File / folder ownership dictates which user or a group owns a file or directory. This controlls the access to files and folder by specifying owner and group permission.

- `chown <options> [user]:[group] `  to change the user and group owner of file / directory.

**Options:**
- ``-R <directory>`` recursive on files and directories. 
- ``-c`` verbosity / log of what changed.

Example:

```bash
# create a file
touch file1.txt

# view user and group
-rw-rw-r-- 1 test test 0 Dec 17 11:05 file1.txt

# change the user owner to surya
sudo chown surya file1.txt

# view perm
ls -l
# -rw-rw-r-- 1 surya test    0 Dec 17 11:05 file1.txt

# change group owner to docker
sudo chown :docker file1.txt

# view perm
ls -l
# -rw-rw-r-- 1 surya docker    0 Dec 17 11:10 file1.txt

# change back group and user to test
sudo chown -c test:test file1.txt 
# changed ownership of 'file1.txt' from surya:docker to test:test

# view perm
ls -l
# -rw-rw-r-- 1 test test    0 Dec 17 11:20 file1.txt
```
